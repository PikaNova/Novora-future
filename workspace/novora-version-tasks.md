# Novora 完整版本任务规划

基线：`novora-remote-audit`，`main`，`0850b00`，版本 `2.7.3`。

本文件合并架构审查、代码质量报告和修复方案，形成逐版本任务清单。每项任务有编号、前置依赖和验收条件；版本号由验收条件驱动，不由日期驱动。

## 版本总览

| 版本 | 主题 | 目标 | 状态 |
|---|---|---|---|
| v2.7.x | 稳定与质量 | 修复正确性缺陷，建立集成门禁 | 规划完成 |
| v2.8.x | 学校考试管理 | 考试元数据、列表、历史、复制 | 未开始 |
| v2.9.x | 学校考试运行中心 | 可靠命令队列、设备态势 | 未开始 |
| v3.0.x | 作者中心 | 独立观测与数据治理 | 未开始 |
| v3.1.x | Windows Agent | 受控执行链路内测 | 未开始 |
| v3.2+ | 扩展 | Linux、楼控、AI、商业化 | 长期 |

## 发布检查清单（每个版本）

1. `npm test` 全部通过。
2. `npm run typecheck:api` 通过。
3. `npm run build` + `npm run serve:build` 通过。
4. `npm run format:check` 通过。
5. 独立数据库集成测试通过（涉及 schema 变更时）。
6. 旧客户端兼容性回归（涉及 API 变更时）。
7. 审计日志覆盖新操作（涉及设备/权限变更时）。
8. 迁移/回滚脚本在集成环境验证（涉及 schema 变更时）。
9. 版本号、CHANGELOG、README 同步更新。

## 计划维护规则

- 每完成一个版本，更新本文件状态列和三份持久化计划文件。
- 版本内任务可调整顺序，但不能跳过前置依赖。
- 新增任务必须带编号和验收条件，不留无出口条件的任务。
